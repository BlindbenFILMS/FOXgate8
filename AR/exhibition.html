Build an exhibition

Group artworks into one room so a single QR code covers all of them. Artworks need to be added with add.html and pushed to the site first.

1 Name the room

2 Pick the artworks

Aim for 10–20 per room. Each one adds about 0.7 MB for visitors to download.

3 Build the room's tracking file

4 Put it on the site

  1. Move the .mind file into the AR\targets folder.
  2. Open AR\artworks.js. Scroll to EXHIBITIONS at the bottom and paste the block below where it says Paste new exhibitions here, with a comma after the } before it.
  3. In GitHub Desktop: commit, then Push origin.
  4. Print the QR code at the room's entrance.
