# MERU SOUND PROMPTS · batch 2 (town life: doors, footsteps, crowds, casino, lanes, cafe, market, lake) · 20 files

Paste each prompt into Runway. Save each file with the **exact name** shown, as MP3, into **audio/meru/**.

## RULES FOR EVERY FILE (same as batch 1)

- **Mono**, 44.1 kHz, MP3 192 kbps.
- **Dry**: no reverb, no echo, no music, no voices with words. The game adds distance + walls itself.
- **Same loudness** for all: about -16 LUFS, peaks no higher than -3 dB. (No need to level or trim; the game does it at load.)
- **No silence** at the start. Tails under 0.3 s unless the prompt says otherwise.
- **LOOPS** must loop **seamlessly**: no fade, no click.
- Crowd loops: **murmur only, no words you can make out**, nothing that stands out (a laugh or shout that repeats every loop gets noticed).
- **2 versions** where asked: two short takes that differ slightly.
