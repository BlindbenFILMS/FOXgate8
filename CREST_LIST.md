# CREST LIST · proposal for Ben (s608, NOT approved yet)
Rules (Ben): a crest is a CHARM, its own CREST slot in CHARMS, worn over any armour. One shape for all (round medallion), only the symbol + colours change.
Earned crests NEVER use a planet letter (those belong to that planet's military). Each world has a crest earned at a milestone; one for the Machine Fleet too.
The symbol does not have to show the quest. Rare crests get a GOLD RIM. Each crest gives a small bonus (mix of combat + life).
