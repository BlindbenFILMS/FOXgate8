# 8 GATES 3D · Sound effect request list: MERU + every Meru job

Same rules as `SFX Request List - Runway.md` (WAV or MP3, mono, 44.1 kHz, about −3 dB peak, clean start, 3 takes each, loops seamless). Style: warm, toon, cosy town; punchy and readable on phone speakers.
**Naming:** every prompt starts with its tag `8G <GROUP> <NAME>:`, so the files sort together. Rename each to `sfx/meru/<key>.mp3`.

**Already made (do not remake):** sword, laser, melee + ranged weapons, supers, robots (`audio/`), menuOpen, menuSelect, toast, questStep, teleport, footstepMetal (`sfx/`).

**How it is grouped.** Meru has 60+ buildings and about 400 jobs, but most jobs use the same few actions (polish, stamp, pour, count coins, saw, hammer…). So sections 1-4 are SHARED kits that every job uses, and section 5 only lists each building's own SIGNATURE sounds. About 190 files in total.
