# GEM PLAN · proposal for Ben (s608, NOT approved yet)
How gems, charms and crests add up. Nothing here is built yet; numbers are a first pass for Ben to change.

## The rules (Ben's picks)
- Every ARMOUR piece and every WEAPON has 2 gem slots:
  - **WORLD slot**: only that world's gem (a Meru piece takes a MERU GEM). Empty until you win or find it.
  - **ANY slot**: any power-up gem.
- Gems are NEVER sold. Found on the planet or given for quests.
- One gem can move between pieces, but only at an armory.
- Armour is bought piece by piece at the planet armory; pieces sell back at half price.
- No stat caps. Numbers stay small instead.
- Related stats STACK (BARTER + TALK both make prices better). No hidden combos.
- Each world's gem fits that world.
- Charms (3 slots) and the crest (its own slot) add on top.

## How many slots a full kit has
| Where | Slots |
|---|---|
| Armour: helmet, chest, shoulders, gauntlets, boots | 5 world + 5 any |
| Weapons: melee + ranged | 2 world + 2 any |
| Charms | 3 |
| Crest | 1 |
| **Total** | **18 bonuses** |

## Gem sizes (needs Ben's call ⚠)
Ben asked for a modest full kit (about +30 % in total) AND world gems of +5 %. Those two don't fit together: 7 world gems at +5 % already make +35 %, before any-gems, charms and the crest.
- **Proposal (fits +30 %):** world gem **+2 %** · any gem **+1 %** (or +10 HP / +2 armour) · charm **+3 %** · crest **+5 %** · full set bonus **+2 %**.
- **Alternative (keep +5 % world gems):** a full kit lands near **+65 %**.

## The stats (24)
Combat: MAX HP · ARMOUR · MELEE · RANGED · SUPER CHARGE · TOUGH (less knockback + stun)
Moving: SPEED · JUMP · SWIM / VEHICLE · PILOT (ship)
Life: GOLD · XP · ENERGY · HEALING (from items) · LUCK (rare drops) · SENSE (hidden items glow nearer)
Town: BARTER · TALK · FRIENDSHIP · CRAFT (jobs pay more) · FISHING · FARMING
Sneaky: STEALTH · STEAL (getting caught: later)

**Stat pairs that stack** (the "combos" players will find):
- Prices = BARTER + TALK
- Loot = LUCK + SENSE
- Front line = MELEE + TOUGH + ARMOUR
- Sharpshooter = RANGED + SUPER CHARGE
- Sneak = STEALTH + STEAL
- Outdoors = FISHING + FARMING
- Travel = SPEED + JUMP + SWIM / VEHICLE
- Friends = TALK + FRIENDSHIP (freed robots help more)
- Space = PILOT + ENERGY

## Charms + crest (on top of gems)
- Existing charms keep their shop bonus (LUCKY GOLF BALL +25 % gold at Birdie's, etc.); those only work in one place.
- New general charms would give +3 % to one stat (for example a TALK charm for the BARTER + TALK pair).
- Crests: CREST_LIST.md (FIRST GATE +5 % XP, and so on).
- Full set bonus: wear all 5 pieces of one world = +2 % (Ben sets what, per world).
