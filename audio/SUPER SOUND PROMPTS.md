# SUPER MOVE SOUND PROMPTS (s339)

Paste each prompt into Runway. **Before downloading, rename each clip to its TITLE** (the bold name, e.g. `super-nova`). Short titles download whole, so no sorting by ear later.

Settings: about 1.5 s unless the prompt says otherwise. Every prompt ends with the same rule line, so the clip comes out clean.

Rule line (already in every prompt): *Isolated single sound effect, dry, close-miked, no music, no voices, no background ambience, clean start, short tail, then silence.*

Save to `audio/supers/<title>.mp3`.
